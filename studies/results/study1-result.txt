NOTES ON THIS RESULT

1. The rho estimator returned 0.000, so no correlation discounting was applied.
   That estimator is not meaningful as written: it compares arbitrary events
   across quarterly cohorts by position, which is not a cross-sectional
   correlation. It is IMMATERIAL here -- the naive p is already 0.491, and
   discounting can only raise it. It must be fixed before any positive result
   is reported.

2. Universe skew. Despite the intent to include mid-caps, the 98 tickers with
   usable events are overwhelmingly S&P 100 constituents. The published effect
   concentrates in SMALL caps and negative news, so this tests where it is
   weakest.

3. Truncation. Median release length was 31,757 chars against a 30,000-char cap,
   so roughly half of releases lost their tail. That tail is mostly financial
   tables with the narrative front-loaded, but it is a real constraint.

4. Alpha decay. Lopez-Lira & Tang report the effect declining as LLM adoption
   rises. This sample is 2024-07 to 2026-08, entirely after the mass-adoption
   period their decay result covers.

5. What was NOT falsified: the model READS well. The scoring-fitness pre-flight
   measured rank correlation 0.939 against human judgement on subtle text, where
   a finance lexicon scored -0.476. Comprehension is real; it simply does not
   translate into predictive content about drift in this sample.
